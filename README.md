# 选题灵感

小红书爆款选题的灵感收集图。每个选题是一个漂浮的点；鼠标悬浮，它会炸开与之相关的内容；点击打开右侧阅读面板，看全文、帖子卡片和连接。内容主要由 agent 填，人也可以手动加。

## 数据放在哪

所有内容都是某一个 Buzz 频道里的普通消息，所以**频道里的每个人（和 agent）看到的是同一张图**：

| 图上的东西 | 频道里的样子 |
| --- | --- |
| 选题（点） | 一条顶层消息，第一行是标题 |
| 🌱 延伸选题 / 📕 小红书帖子 / 📝 文稿 / 🔬 深入研究 / 💬 笔记 | 该选题话题串里的回复，以对应的 emoji 开头 |
| 继续深入（内容下面再挂内容） | 回复的回复 |
| 🔗 选题之间的连接 | 话题串里一条以 🔗 开头的回复 |
| 频道公告（不上图） | 以 📌 开头的顶层消息 |

## 让 agent 填

装了本插件的设备上，每个 Buzz agent 都会多出 5 个工具（agent 需要先被拉进选题频道）：

| 工具 | 作用 |
| --- | --- |
| `xhs_topics_list` | 列出选题；带 `topic` 时返回该选题的全部内容 |
| `xhs_topics_add` | 丢一个新选题（同名不重复） |
| `xhs_topics_add_content` | 填延伸选题 / 文稿 / 研究 / 笔记，可用 `parent` 挂在某条内容下 |
| `xhs_topics_add_post` | 挂一篇小红书帖子（同一篇不重复） |
| `xhs_topics_link` | 连接两个选题 |

直接对 agent 说人话即可，例如“给『打工人带饭』这个选题找 5 篇对标帖子并拆解亮点，再延伸 3 个角度”。

## 小红书帖子

帖子在面板里显示为卡片：标题、作者、赞藏评、亮点、标签、「打开小红书」按钮。它能读三种写法：

1. agent 工具写出的结构化格式：

   ```
   📕 帖子标题
   https://www.xiaohongshu.com/explore/…?xsec_token=…
   作者：昵称 ｜ 赞 3.2w ｜ 藏 1.1w ｜ 评 856
   亮点：这篇为什么火、可以借鉴什么
   标签：#带饭 #打工人
   ```

2. 小红书 App 里「分享 → 复制链接」得到的整段文字（自动提取标题和作者，去掉口令和广告语）。
3. 只贴一个链接，加不加说明都行。

链接请保留完整（含 `xsec_token`），否则小红书网页端打不开。插件本身不抓取小红书：数据由 agent 或人填入，这样不依赖登录态，也不会被反爬拦住。

## 使用

1. 频道名字里带「选题」「小红书」或 `xhs` 会被自动选中，也可以在右上角切换。
2. 左上角输入框丢选题；悬浮看炸开的内容；点击选题或内容卡片打开阅读面板。
3. 面板里「＋ 添加」手动填内容或上传 txt / md 文稿，「🔗 连接」后点另一个选题建立连接，卡片上的「深入」在该内容下继续挂内容。
4. 拖动平移，滚轮缩放，Esc 逐层退出。

只能删除自己发的选题、内容和连接。

## 安装

每位成员各自安装一次：**Settings → Plugins → Manage plugins → Add**，在 Add from folder 下点 **Browse** 选择本文件夹，确认后 Install plugin。本插件不申请任何主机权限（无网络、文件、进程访问）。

## 已知限制

- 一个频道最多显示最近约 500 条顶层消息及其回复。
- 消息被编辑后，图上仍显示原始内容。
- 文稿上传只支持 txt / md，单条上限 2 万字。
- 帖子卡片不显示封面图。
